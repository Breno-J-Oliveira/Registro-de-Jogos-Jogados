## 🎯 Sobre o Projeto

Este projeto é um **Sistema de Cadastro de Jogos**, onde é possível registrar informações como:

- 🎮 Nome do jogo  
- 🧭 Gênero  
- 🖥 Plataforma  
- 📆 Ano de lançamento  
- 💰 Preço pago  
- ⭐ Nota de avaliação  

O objetivo deste projeto é **praticar CRUD completo em PHP**, interação com banco de dados MySQL e estilização com CSS.

---

## ⚙️ Funcionalidades

| Função | Descrição |
|------|-----------|
| ➕ Adicionar Jogos | Cadastro de novos jogos no sistema |
| ✏️ Editar Jogos | Permite alterar todos os dados cadastrados |
| 🗑 Excluir Jogos | Remove um jogo permanentemente do banco |
| 📋 Listagem Completa | Todos os jogos aparecem organizados em tabela |
| ⭐ Avaliação | Cada jogo possui nota de 0 a 10 |
